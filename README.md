# Guestbook Web App

Простий вебдодаток "Гостьова книга", який дозволяє користувачам залишати коментарі та переглядати список усіх залишених записів.

## Системні вимоги

Перед початком роботи переконайтеся, що у вас встановлені:
* **JDK:** 21
* **Maven:** 3.9 або вище

## Запуск

Щоб запустити додаток локально, виконайте наступну команду в терміналі (у кореневій директорії проєкту):

```bash
mvn clean compile jetty:run
```

Після успішного запуску додаток буде доступний за адресою:
**URL:** [http://localhost:8080/](http://localhost:8080/)

## База даних (H2)

Додаток використовує вбудовану базу даних H2 для зберігання коментарів.

* **JDBC URL:** `jdbc:h2:file:./data/guest;AUTO_SERVER=TRUE`
* **Шлях до файлу:** `./data/guest.mv.db`

## API Ендпоїнти

Додаток надає наступний REST API для роботи з коментарями:

* `GET /comments`
    * **Опис:** Повертає масив усіх залишених коментарів у форматі JSON.
    * **Успішна відповідь:** `200 OK`

* `POST /comments`
    * **Опис:** Додає новий коментар. Тіло запиту (JSON) повинно містити поля `author` (автор) та `text` (текст коментаря).
    * **Успішна відповідь:** `204 No Content`
